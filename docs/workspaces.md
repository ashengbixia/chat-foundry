# 模型连接、助手、会话分支与文档协作

## 升级现有安装

本批数据库版本为 `a70e18c9d402`，新增命名模型连接、助手、分支元数据、知识库共享授权与文档版本表。已有个人模型配置会复制为“已有模型服务”，保留原来的加密 Key 与各模型能力配置。

更新前备份并停止后端，再按部署文档执行数据库升级。开发环境在项目根目录执行：

```shell
python -m backend.app.core.db_setup --upgrade
```

Windows 服务部署按 `deploy/windows/README.md` 第 5 节的完整更新流程，使用 `runtime.py --env-file <运行目录>/server.env upgrade` 升级实际运行数据库；不要在另一套数据目录执行迁移。依赖安装仍以 `backend/requirements.txt` 为准，本轮未提交的工具改进另增加了 `tzdata`。前端源码更新后需要重新构建；部署包用户使用同版本构建产物。

## 命名模型连接

1. 打开设置 → 模型服务，填写地址、认证方式、模型 ID 与能力配置。
2. “另存为命名连接”保存另一份连接；普通“保存”更新当前连接。
3. 设置 → 连接与助手中点击连接切换并编辑。输入区模型选择器聚合各连接实际返回的模型，展示所属连接，选择时同时切换连接和模型。

每账号最多 20 个连接。各连接独立保存加密 Key 和模型能力；页面不回显明文或密文。一个连接发现模型失败不会隐藏其他连接；不支持模型发现的服务可手动填写模型 ID。恢复服务器默认只取消个人连接的激活，已保存连接需要在清单中单独删除。被助手引用的连接须先解除引用才能删除。

## 我的助手

设置 → 连接与助手 → 新建助手，保存名称、系统提示词、连接、可选模型 ID、工具范围和默认知识库。工具使用勾选清单；默认范围与普通聊天相同，取消默认范围后全部不选表示禁用工具。工具仍受账号开关、联网开关、子任务范围和文件授权限制。

空白对话页选择助手后，默认知识库显示在输入区，可在发送前移除或更换。发送第一条消息才创建会话。助手使用专用连接或模型时，输入区显示固定配置；修改助手配置会影响其会话后续回答，正在进行的回答沿用开始时的配置。删除助手保留历史对话，后续转为普通模式。已删除或已撤销授权的默认知识库不再自动添加。

## 编辑、重新生成与分支

消息下方可编辑用户问题、重新生成助手回答，或从任意消息创建分支。编辑和重新生成会复制截至对应用户问题的消息，再在新分支生成；普通分支复制至所选消息。新旧对话都在历史中保留，顶部版本选择器用于切换同一组分支。

复制包含消息正文、工具记录、附件与引用快照、压缩检查点；不会恢复已经移出会话的文件或已撤销的知识库授权，也不会重新启动原子任务。生成期间须先停止再编辑。分支是独立会话，不是在原会话内部维护消息树；两者后续互不覆盖。

## 原文件与文档版本

文件管理提供打开原文件、下载、上传新版本和版本记录。浏览器支持内联 PDF 查看；引用面板可以打开 PDF 对应页。其他格式提供原文件下载，仍可查看提取文本和引用高亮，不承诺 Word、Excel 的原版式在线渲染。

新版本保存为新的文件与索引，替换所有者知识库中的成员关联。原文件、历史消息及其证据快照保持原版本；当前会话显式附件也保持原版本，需要使用新版时重新选择。只能从最新版本继续更新；相同正文复用现有文件，不重复建立版本。独立文件自动发现默认排除已被新版本替代的旧文件，旧版可通过版本记录和原会话查阅。所有版本均计入存储额度。

## 共享知识库

所有者在知识库详情展开“共享给其他账号”，输入对方的登录账号。接收者可以发现、选择、检索和阅读库内资料，不能上传、改名、移出文件、重建索引、删除或继续共享。共享不会授予所有者的其他知识库、历史会话或其他版本文件的访问权。

撤销共享立即移除接收者会话中的该库关联，后续工具与原文件请求重新校验授权。已生成回答中的引用快照仍作为历史记录保留，撤销共享不追溯删除此前已经交付的内容。
